## 🌟 About the Project

This Weather App allows users to:

- Search for the current weather by entering any city name
- View live weather data such as:
  - 🌡️ Temperature
  - 🌧️ Weather condition (Rain, Sunny, Cloudy, etc.)
  - 💧 Humidity
  - 🌬️ Wind speed
- Automatically adjust styling based on the weather condition
- Use on desktop, tablet, and mobile devices thanks to a responsive layout

## ✨ Features

- 🔍 Search any city and get accurate weather instantly  
- ⚙️ Uses the powerful OpenWeatherMap API  
- 🎨 Custom UI with icons for visual feedback  
- 📱 Mobile-first responsive design  
- 🧠 Written in vanilla JavaScript (no frameworks)  
- 🌈 CSS gradients and transitions for modern look
